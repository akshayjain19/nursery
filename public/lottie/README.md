# Hero plant Lottie

Drop your Lottie JSON file here as:

**`hero-plant.json`**

Full path: `public/lottie/hero-plant.json`

The homepage hero loads this file automatically. Export from LottieFiles or After Effects as **JSON** (not `.lottie` binary — if you have `.lottie`, re-export as JSON from LottieFiles).

After adding the file, restart `npm run dev` and hard-refresh the browser.
